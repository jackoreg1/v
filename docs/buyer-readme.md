## Read me first

Thanks. What you have is one file. Not an app, not a login, not a subscription.

It works like this: you save the file, you tap it, it opens in your browser and
it works. There is nothing to install and nothing to sign up to. It keeps
working with the wifi off and on a plane.

### Open it

**iPhone or iPad.** Save the file to Files. Tap it. It opens. Then hit the
share button and Add to Home Screen, and from now on tap that icon instead.
That is the bit worth doing, because it turns the file into something that
looks and behaves like an app.

**Android.** Save it to your files and open it with Chrome. Then the three dots,
Add to Home screen.

**Laptop.** Put it somewhere you are not going to tidy away later. Documents is
fine, Dropbox or iCloud is fine, it still opens straight off the disk. Then
bookmark it.

### The one thing that catches people out

Whatever you type into it is saved in the browser you opened it in, on that
device, and nowhere else. There is no server. Nothing you type ever reaches me
or anybody else, which is the point.

The flip side is that a different browser, or a different phone, is a different
set of saved stuff. It is not broken, it is what having no account costs you.

So two rules:

1. **Open it the same way every time.** That is why the home screen icon is
   worth the thirty seconds.
2. **Clearing your browsing data will wipe it.** If the tool has a backup button,
   use it now and again and keep the file somewhere. If you are moving to a new
   phone, back up first.

saw. If it will not work for you, say the word and I will refund you. It is a
